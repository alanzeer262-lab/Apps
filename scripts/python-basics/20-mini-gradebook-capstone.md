**Target:** 3–4 minutes. This is an orientation, not a solution walkthrough. Learners must solve all five graded milestones in PyLearn; do not show completed function bodies, solutions, or the five final sample answers.

## Scene 1 — Your mission
**Visual:** Show the sample `records` list with five name-score tuples. Do not show any milestone solutions.
**Narration:** “You've learned Python's basic tools one at a time. Now you'll combine them to answer questions about a small gradebook. Each record is a tuple containing a learner's name and score, and a list holds all the records.”

## Scene 2 — Inspect before analyzing
**Visual:** Highlight one tuple, then show the generic loop `for name, score in records:` and `print(len(records))`. This is the capstone's inspection step, not a milestone solution.
**Narration:** “Before analyzing data, inspect its shape. Each tuple can be unpacked into a name and a score. You can loop through the records and check how many records the list contains. This helps you understand what you're working with before solving the tasks.”

## Scene 3 — Five milestones, five kinds of thinking
**Visual:** Show only milestone titles, one at a time: **Calculate an average**; **Find the top scorer**; **Filter who passed**; **Map names to letter grades**; **Count grade categories**. Do not show code, output values, thresholds, or completed dictionaries.
**Narration:** “The capstone has five graded milestones. First, calculate an average. Then find the highest scorer. Next, filter the people who meet a cutoff. After that, map names to letter grades. Finally, count the grade categories. Each task uses ideas you've already practiced, but you must write and test the function yourself.”

## Scene 4 — A strategy, not an answer
**Visual:** Show a reusable three-question checklist: **What data do I have? What result is required? What smaller steps will get me there?** Then show a boundary-test icon without listing the exact boundary answers.
**Narration:** “If you get stuck, don't try to solve everything at once. Ask what data you have, what result the function must return, and what smaller steps will get you there. Test small pieces. For rules with thresholds, test values on either side of a boundary.”

## Scene 5 — Go to the app
**Visual:** Show PyLearn app screen/card: **Mini Gradebook Capstone** with five milestone tiles, all shown as tasks to complete—not as completed. Button text: “Start Milestone 1”.
**Narration:** “Now open the Mini Gradebook Capstone in PyLearn. Complete the five milestones in order. Read each prompt, write your own function, run the tests, and use the hints only when you need them. The app checks your work; watching this video does not complete the milestones for you.”

## Final call to action — required for YouTube and in-app versions

Let's practise with a small C S V-shaped input. Extra spaces can make values inconsistent, so trimming is a useful loader responsibility.

Trimming removes surrounding whitespace. It does not convert the score to a number or decide whether it is in range.

The value is still a string. That is expected at the loading stage; conversion and validation belong in the next stage.

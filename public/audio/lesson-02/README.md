# Lesson 02 narration audio

This folder is reserved for the approved narration audio for **Lesson 02 — Variables and Data Types**.

## What to put here

After generating narration in Runway with the exact approved ElevenLabs v3 Kendrick voice, place the MP3 part files here:

- `part-01.mp3`
- `part-02.mp3`

Keep the parts in script order. Do not put Lesson 1 audio here. If the narration is exported as one MP3, name it `full-narration.mp3` and tell the assistant so the workflow can be updated to use that file.

Once the files are in this folder and committed to the `main` branch, production resumes with checking the audio, transcribing the actual narration, deriving scene timing from real timestamps, and aligning the video. **Do not invent timing from the script.**

Narration script: `docs/LESSON_02_NARRATION_SCRIPT.md`
